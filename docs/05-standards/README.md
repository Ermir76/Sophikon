# Engineering Standards

Version: 1.0
Date: 2026-03-20

## Purpose

This folder defines cross-cutting engineering standards for Sophikon.
These are governance rules that apply across SDLC phases.

Use this folder for "how we build and verify quality".
Do not put requirements, architecture design, or sprint tracking here.

## Scope

| Area | Standard |
| --- | --- |
| Backend | `01-backend-standards.md` |
| Frontend | `02-frontend-standards.md` |
| AI Agents | `03-ai-agent-standards.md` |
| Testing | `04-testing-standards.md` |
| UX | `05-ux-standards.md` |

## SDLC Position

- `01-requirements`: what to build
- `02-design`: system design
- `03-implementation`: execution tracking
- `04-testing`: test planning and reporting
- `05-standards`: engineering rules and quality guardrails
