## Expert Consensus

Themes raised by 5+ experts independently:

1. **"Missing invitation details" dead end** (5 experts) — The single biggest UX gap. A stranded user with no escape route.
2. **Notification dropdown overloaded** (Norman, Nielsen, Garrett + Krug, Hall on labeling) — Settings don't belong in a notification feed. Separate concerns.
3. **Touch targets undersized** (Wroblewski, Ive, Levey) — Multiple interactive elements well below 44px minimum, especially in the notification panel.
4. **Copy and labels need humanizing** (Krug, Hall, Norman, Rams) — "Access list", "Locale", "Live", "Missing invitation details", notification setting labels all use developer-speak.
